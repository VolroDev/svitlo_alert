# svitlo_alert

Telegram-бот, що попереджає про зміну зон у графіку відключень АТ «Миколаївобленерго»
([off.energy.mk.ua](https://off.energy.mk.ua/)). Специфікація: [docs/SPEC.md](docs/SPEC.md).

## Як працює

- Під час запуску й кожні 15 хв (00:00, 00:15, 00:30, …) бот читає графік з API сайту
  та зберігає останню версію в `data/schedule_cache.json`.
- Раз на хвилину перевіряє канал [@mk_energy_ua](https://t.me/mk_energy_ua). Коли там з'являється
  новий запис, графік перечитується одразу і ще раз через 5 хв.
- Кольори зон узяті з легенди сайту: 🟢 «Є світло», 🟡 «Електропостачання можливе»,
  🔴 «Заплановане/Актуальне відключення».
- За обрану кількість хвилин до зміни зони користувач отримує повідомлення:
  - 🟢→🟡: попередження про жовту зону з часом;
  - 🟡→🔴 (і 🟢→🔴): попередження про відключення;
  - 🔴→🟡, 🟡→🟢 (і 🔴→🟢): «можливе світло»;
  - колір не змінюється: нічого.

## Команди бота

| Команда | Дія |
|---|---|
| `/start` | підписатися: обрати групу та час попередження |
| `/status` | поточна зона, наступна зміна та графік на сьогодні |
| `/group` | змінити групу |
| `/time` | змінити, за скільки хвилин попереджати (5/10/15/30/60) |
| `/stop` | відписатися (налаштування видаляються) |

## Запуск

Потрібен Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows; на Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux: cp .env.example .env
# впишіть у .env токен бота від @BotFather
python main.py
```

Тести: `python -m unittest discover -s tests -t .`
